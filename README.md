# Luis Sepúlveda

Construyo **LikePlatform**: una base Laravel + Livewire para operar un negocio conversando con un
agente. Sobre esa base se montan módulos de producto (CRM, facturación, documentos).

> **El kit es MIT. El producto es AGPL.**

## Qué hay aquí

- **[lnx](https://github.com/luinuxscl/lnx)** · el kit — `MIT`. Autenticación con passkeys y 2FA,
  permisos por rol, navegación gestionada, theming, APIs, MCP de lectura, IA con cuotas y consumo, y
  despliegue de fábrica. La base con la que se levanta una aplicación completa.
- **[lnx-ui](https://github.com/luinuxscl/lnx-ui)** · componentes Blade compartidos — `MIT`. Tablas,
  timeline, headers, mail UI.
- **Producto** — el módulo CRM, su cáscara y el agente del producto se publican aparte bajo
  `AGPL-3.0-or-later`.

## Stack

`PHP` · `Laravel` · `Livewire` · `Flux UI` · `Tailwind CSS` · `PostgreSQL` · `Docker` · `Pest`
